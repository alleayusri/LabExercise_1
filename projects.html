Research-based ML project predicting diabetes risk using a dataset of over 70,000 records. Implemented and compared Decision Tree and Gradient Boosting models. Evaluated using accuracy, precision, recall, F1-score, and ROC-AUC.

A complete SRS for the Etiqa eMoney digital payout platform. Covers wallet management,payout processing, insurance claims, and audit log modules — with use case diagrams, system models, security requirements, regulatory compliance, and third-party integration specifications.

Project 5: Daily Fresh Ordering System

To create a two-way online ordering system that enables customers to make orders on their own, unlike the old existing system which only allows customers to see menus and pick up food after making payment.
